# Приложение: как стандарт проверялся

Не входит в стандарт. Здесь лежит то, что относится к его проверке, а не к самому протоколу.

Перед публикацией протокол прогнали через реальные прайс-листы операторов: 166 тарифных вариантов разобраны в термины стандарта. Разбор показал, что почти всё укладывается в L1 и L2; уровень L3 понадобился ровно двум конструкциям — бесплатному периоду хранения и матрице «цена за заказ по числу хрупких товаров» (см. [уровни соответствия](../modules/pricing/README.md)).

| Реестр | Что внутри |
|---|---|
| [`integrity_checks`](integrity_checks.csv) | Декларация проверок валидатора. Расхождение этого реестра с кодом `validate.py` само является блокирующей ошибкой |
| [`residual_gaps`](residual_gaps.csv) | Находки проверки: конструкции, которых стандарту не хватало, и правки модулей, которыми они закрыты |
| [`rules`](rules.csv) | `SRC-*` — требования к нормализации прайса при импорте |
| [`00_overview`](00_overview.csv) | Сводка по составу стандарта |

## Находки проверки

`residual_gaps` — журнал того, что разбор реальных прайсов потребовал добавить или поменять в стандарте: ступенчатое хранение по возрасту партии, графики маршрутов, атомарные услуги, разведение модификатора и метода расчёта, реестр пунктов назначения. Каждая строка ссылается на правку, которой закрыта; открытая строка означает признанный пробел выразительности, ждущий правки модуля.

Имена операторов обезличены (`оператор A`, `оператор B`). Вопросы к качеству исходных прайс-листов — пустые цены, непокрытые интервалы веса, неуказанный режим НДС — в этот реестр не входят: это разговор с владельцем конкретного прайса, а не дефект стандарта.

## Чего здесь нет

Самого разбора: 166 размеченных тарифных вариантов, ссылки на файлы-источники, размерные профили и графики маршрутов конкретных операторов. Это данные их владельцев, публиковать их мы не вправе.

Поэтому валидатор в этом репозитории помечает шесть проверок как `SKIP` — им нужны данные разбора:

```
[SKIP] Ступенчатые строки импорта без обязательных полей  — нет данных разбора прайсов
```

Положите рядом `appendix/price_imports.csv` в том же формате, и эти шесть проверок выполнятся на ваших данных.
