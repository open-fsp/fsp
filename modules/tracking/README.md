# FSP Tracking — планируется

События по заказу и остатки на складе оператора.

Статус `planned`: реестров нет, объявить модуль в манифесте нельзя. Зависит от [FSP Order](../order), поэтому не может быть описан раньше него.

## Что войдёт

- События заказа: принят, обработан, отгружен, доставлен, возвращён — с временем и складом.
- Остатки: сколько единиц лежит у оператора по SKU, партии и режиму хранения.
- Расхождения: недостача и излишки при приёмке, брак, недостоверные габариты.
